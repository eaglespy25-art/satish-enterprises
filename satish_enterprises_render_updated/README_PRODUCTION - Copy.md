# Satish Enterprises Production Package

This is the consolidated deployment package containing:
- PostgreSQL backend
- Razorpay online payments
- Product/variant inventory
- Order management
- Shipping/tracking
- Returns/refunds
- Customer account
- Notifications
- Email/WhatsApp adapters
- Role-based admin
- Analytics
- Docker production build
- Nginx reverse proxy
- Health checks
- Backup script

Start with `PRODUCTION_DEPLOYMENT.md`.
