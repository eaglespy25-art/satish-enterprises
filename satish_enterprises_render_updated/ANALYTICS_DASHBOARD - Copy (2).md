# Admin Analytics Dashboard

Built:
- Revenue
- Orders
- Paid orders
- Delivered orders
- Refund amount/count
- New customers
- Low-stock count
- Daily sales/orders
- Top products by sales
- Units sold and current stock
- Customer order count and spend
- 7/30/90/365 day filters
- Role-based API access

Metrics are calculated from PostgreSQL data, not hard-coded values.
